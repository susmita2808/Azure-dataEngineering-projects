## Featured Project

### 🔹 Real-Time Data Pipeline (Batch + Streaming)

Built a production-style hybrid pipeline using Azure services to process both batch and real-time data.

**Key Highlights:**
- Hybrid pipeline (ADF + Event Hub)
- Medallion Architecture (Bronze → Silver → Gold)
- Secure access using Key Vault + OAuth
- Databricks-based transformations (PySpark)
- Unity Catalog integration
- Business KPI generation (Gold layer)
